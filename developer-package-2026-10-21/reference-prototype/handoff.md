# Образец UX, не код для переноса

Запустите локальный HTTP-сервер из инструкции в ../README.md. Выберите пример подготовки или позднего входа. Подтверждения влияют только на данные этой вкладки.

Для реализации читать ../00_AGENT_BRIEF.md и документы 01–05. Они имеют приоритет над копирайтом, порядком Hero и упрощениями этого макета. Дизайн брать из текущего приложения.

Прототип использует несколько последовательных UI-итераций; это намеренно сохраненный просмотр последнего состояния, а не рекомендуемая архитектура. Последними загружаются flow-model.js и journey-ui.js. Node-проверка: node flow-model.test.cjs.
