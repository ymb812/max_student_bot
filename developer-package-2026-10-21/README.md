2. [02_CONTENT_AND_SOURCES.md](02_CONTENT_AND_SOURCES.md) — содержание задач, CTA, источники и правило демонстрационных сроков.
3. [03_DATA_AND_IMPLEMENTATION.md](03_DATA_AND_IMPLEMENTATION.md) — контракт, события, миграция и порядок реализации.
4. [04_ACCEPTANCE.md](04_ACCEPTANCE.md) — проверяемые сценарии и критерии готовности.
5. [05_DECISIONS_AND_LIMITS.md](05_DECISIONS_AND_LIMITS.md) — принятые решения, исключенные варианты и ограничения доказательств.

Исследована локальная версия source/ на commit `61d07d91edc75bc02f9737234aac7b26de12a889`. Перед этой задачей git pull не выполнялся: пользователь просил документы, не обновление приложения. Приоритет в рамках новой задачи: явные указания пользователя → этот пакет → текущие правила проекта для неизменяемых частей. Старые заметки и прототип — поясняющие материалы, а не дополнительные конкурирующие требования. Пакет не разрешает обходить ограничения среды агента или автоматически публиковать изменения.

## Образец поведения

В ZIP включена папка `reference-prototype/`: автономные HTML/CSS/JS последней итерации и отдельный README. Запуск: `python -m http.server 8771 --bind 127.0.0.1 --directory reference-prototype`, затем http://127.0.0.1:8771/ . Порт можно заменить. Для проекта исходник образца находится в `prototypes/adaptive-onboarding/`.

Прототип иллюстрирует состояния и переходы. Не переносить его код, стили, sessionStorage как серверное хранилище, фиксированный порядок Hero или упрощенную отмену в приложение. Не требовать воспроизведения внешнего вида прототипа. Дизайн-эталон — текущие экраны самого приложения.
