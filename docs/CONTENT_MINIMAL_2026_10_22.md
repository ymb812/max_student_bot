- C01: `student-copy.js/taskInstruction` выбирает уточнение необходимости и места процедуры только для M05/M06/M10 в `conditional`/`needs_review`. Тексты сохранённых результатов, ожидания, прошлого действия, завершения и `requires_recheck` имеют прежний приоритет. `student-ui.js/reviewView` использует ту же инструкцию для этих трёх семейств. Обычное действие не изменено, исходный текст доступен в справке «Порядок действий». Ответ отдела не подтверждает применимость и не завершает процедуру.
- C02: `student.js/taskInformationView` при наличии метаданных `prototype_timing` показывает «Условия демонстрационного плана» и «Основание расчёта даты». Сведения источников, даты их проверок и `norm_confidence` сохранены. Для обычного расчёта прежние подписи остаются. Каталог confidence, формулы и флаг режима не изменены.
- C03: в карточке без дат текст о неподтверждённом сроке выбирается только для приглашения с источником E1, `confidence=U`, без `checked_at`. Это существующий признак непроверенной инструкции ЛЭТИ. Утверждение об отсутствии срока в прочих инструкциях этим пакетом не меняется.
- C05: только список `sutd.M03`: индекс 2 — один из трёх документов об обучении и две копии выбранного документа; индекс 3 — нотариальный перевод паспорта и одна копия. Индексы 0/1, длина списка, количество копий и списки ЛЭТИ сохранены. Карточка, форма остатка, история и онбординг используют опубликованный список. При обновлении seed штатный механизм сохраняет старую версию правила, добавляет новую; прежний результат с `missing_documents=[2,3]` продолжает указывать на те же документы. Исторические снимки не переписываются.
