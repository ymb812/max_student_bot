## Поведение

- DR01: support-envelope review оставляет `clarified` после `question_sent`. Полученный ответ сохраняется как `needs_help`; `needs_review` и незавершённая процедура сохраняются. Ответ не подтверждает применимость.
- DR02: у уже приехавшего студента отсутствие даты въезда не запрещает результаты `office` — частичный/полный комплект. Отсутствие только даты прибытия ЛЭТИ тоже ограничивает расчёт, но не запись фактической передачи. Прочие conditional/review-основания не обходятся. Дата не подставляется; тот же первоначальный эпизод при уточнении даты сохраняет ключ и результаты. Новый въезд создаёт отдельный эпизод по прежним правилам.
- DR04: контекст первичной визы и её будущего продления возникает только при факте существующего документа. Подача не сопровождается утверждением о сроке полученной визы. Старые snapshots с преждевременным document context также фильтруются при показе. Полученная виза без срока явно показывает неизвестность срока.
- DR05: `revisionDetails` показывает изменение `context_dates.document_expiry` первичной визы отдельной парой «Окончание визы: до/после», включая неизвестное значение. Изменения цикла продления остаются отдельными строками. Дата получения не подменяется окончанием.
- DR07: инструкция partial ссылается на оставшиеся документы ниже; история явно помечает «Осталось передать». Пустой остаток остаётся неизвестным, не завершённым комплектом. Diff уже сравнивал остаток и сохраняет это поведение.
- DR08: до фактического приезда группа неактуального приглашения называется «Больше не требуется для подготовки»; карточка показывает существующую причину про полученную визу. Неподтверждённое приглашение не становится completed. После приезда сохраняется прошлый контекст группы и причины.
- DR11: счётчик «Выполнено действий: N» без ошибки склонения. Контракт формы поездки не менялся.

## Совместимость и проверки

Миграции и новые поля профиля/событий не нужны. Схема результатов, допустимые учебные и миграционные статусы, календарные формулы, опубликованный каталог и транспорт не менялись. Новый тест `tests/test_deployed_review.py` проверяет сохранение через API, уточнение эпизода, исправление/отмену и независимую регистрацию. `tests/deployed-review.test.cjs` проверяет старые снимки и пары визовых дат. `scripts/check_deployed_review.cjs --baseline` воспроизводит исходные ошибки на исходной версии; без флага выполняет приёмку исправлений. Использовать только localhost и новую synthetic БД.

Отсутствие новой ошибки в тестах не является подтверждением выкладки или реального MAX. Точный объём выполненной браузерной матрицы и ограничения приведены в COVERAGE.
