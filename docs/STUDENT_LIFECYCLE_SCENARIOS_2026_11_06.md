# Каталог ситуаций иностранного студента — 06.11.2026

Связанное [исследование, метод и реестр источников](STUDENT_LIFECYCLE_RESEARCH_2026_11_06.md). 50 сценариев — карта охвата, а не 50 проверенных инструкций или обещание реализовать их все. Группы упорядочены для чтения; реальная жизнь содержит параллельные процессы, повторы и возвраты.

**Обозначения.** `P` — подтверждён узкий факт официальной процедуры; `C` — частичная опора/разъяснение; `U` — порядок не установлен. Оценка относится к указанному основанию, не ко всем действиям строки. «Результат для исследования» и «кого спросить» — предложенные критерии и участники, а не подтверждённая оргструктура вуза. У каждой строки с `U` нужно установить владельца и первоисточник.

## Граница охвата

Ни один из 50 сценариев не объявлен полностью готовым для автоматизации. Каталог не устанавливает частоту проблем, приоритет функций или полноту существующего кода. Для каждой строки следующий предметный проход должен дать карточку знания из исследования: действующее основание, условия, действия, документы, ответственного, результат, срок при наличии и альтернативный путь. Сложные строки могут разделиться на несколько карточек после проверки.
