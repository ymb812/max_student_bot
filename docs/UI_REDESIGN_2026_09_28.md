# Обновление интерфейса 28.09.2026

Основание: запрос пользователя убрать шаблонный презентационный вид, MASTER FINAL §10–11. Scope, API, rules engine, каталог, формулы сроков и данные MAX не меняются. Презентации и финальный архив собираются отдельным последующим шагом.

## Изменения

- Светлый фон, компактная типографика, один синий акцент, системные шрифты и небольшие SVG-иконки. Главный экран сразу показывает действия вместо большого слогана и декоративного счётчика.
- План — единый список: название, краткое действие, срок/неопределённость, тип срока и пользовательский статус. Категории заменили технические M-коды в student UI. Вкладки и приоритеты по-прежнему берутся из roadmap.
- На телефоне нижняя навигация «План / Событие / Данные», карточка задачи открывается широкой нижней панелью. На ПК остаётся боковая навигация.
- В карточке статус расположен до длинного текста; государственные, университетские, подготовительные даты и окончание документа разделены. Документы и контакт видны сразу; причины и источники раскрываются. Недостающие поля подписаны на выбранном языке.
- «Мои данные» сгруппированы по учёбе/пребыванию и документам/процедурам. Браузерные демо-профили остаются независимыми входными данными обычного движка; на реальном MAX аккаунте переключателей нет.
- В истории можно открыть завершённые и прежние задачи. Ручную отметку завершения можно изменить; заменённая задача и выполнение, основанное на событии, отображаются без недоступного ручного изменения. Для последнего исправляется само событие.
- Админка использует тот же визуальный стиль; мобильная форма и таблица помещаются в доступную ширину. Публикация и полномочия редактора не меняются.

## Проверка

Локальная изолированная SQLite-база, BOT_TRANSPORT=disabled. Пройдены обычный onboarding, неизвестные данные, независимые профили СПбГУПТД/ЛЭТИ, RU/EN, сохранение формы и статуса после перезагрузки, завершение задачи и возврат из истории, смена адреса и отмена с пересчётом. При неизвестной единице времени ЛЭТИ точная дата не появляется. Проверены раздельные даты рекомендации и документа СПбГУПТД, история до/после, просмотр архивной задачи без редактирования статуса.

В браузере проверены desktop, student viewport 390×844 и admin ширина 320: без горизонтального переполнения страницы. Локальный вход редактора, каталог и новая форма проверены без публикации. Синтаксис всех трёх JS-файлов проходит; 34 backend-теста проходят (предупреждение сторонней библиотеки, без ошибок).

Выкладка: только шесть файлов app/static и документация внутри /opt/max; пересобирается только app. Секреты, SQLite volume, общий Caddy и другие проекты сохраняются. Перед выкладкой сохраняется предыдущая версия static и фиксируются image/container IDs. Результат выкладки отражается в IMPLEMENTATION_STATUS.md.

После выкладки: app healthy; оба HTTPS-адреса возвращают 200; static-файлы совпадают с локальными. ID всех других работающих контейнеров не изменились. В публичном браузерном демо после reload открылся новый UI, сохранился ранее установленный статус «В процессе». Проверена карточка визы: рекомендация вуза 5 октября и окончание документа 4 декабря остаются отдельными датами. Снимки интерфейса и технический receipt сохранены локально в игнорируемой .local; презентации не пересобирались.

Пользователь оценил первый проход как улучшение; дальнейший полный редизайн планируется отдельно, возможно с подходящими навыками/инструментами дизайна. Человеческая RU/EN вычитка остаётся перед сдачей. Локальная браузерная проверка адаптивности не заменяет просмотр после обновления на устройстве пользователя.
