Новый UI выложен и пройден в обычном браузере: `BROWSER_ACCEPTANCE_2026_09_30.md`. Финальные материалы готовятся по `PRESENTATION_CONTENT.md`. Перед загрузкой проверить совпадение имени архива и SHA256 на первом слайде с фактическим `.zip.sha256`. Старые архивы не включают исправления приёмки. Человеческая вычитка RU/EN и, если команда хочет отдельный протокол внутри MAX, проверка новой экранной системы на устройстве остаются за командой.

Дополнение организаторов 30.09: загрузить PDF либо ZIP (презентация + код) размером до 50 МБ с именем `Хакатон MAX - Забота о людях - MarketKit` и нужным расширением. Если кабинет допускает один файл, поместить финальный закрытый PDF, source archive и `.zip.sha256` во внешний ZIP с этим именем. Результаты обещаны 14 октября на почту регистрации.

1. **Вычитка.** Попросить аналитика открыть https://max.market-kit.ru, пройти «Попробовать с начала» и в «Мои данные» выбрать полный профиль СПбГУПТД. Просмотреть карточки и источники, переключить RU/EN. Проверить понятность действий, сохранение различия локальной рекомендации и закона, явные ограничения неизвестных данных. При замечаниях передать список правок разработчику до фиксации архива. Проверить имена/роли команды в PDF.
2. **Открытая презентация, если нужна.** После финальной сборки импортировать публичный PPTX в Google Slides вместо старой версии. Эта копия будет без секретов.
3. **Закрытая конкурсная презентация.** После сборки прикрепить в личном кабинете хакатона закрытый служебный PDF. На первом слайде должны быть bot URL, API, тестовые ключи, token, архив/hash и сценарий. Файл с доступами нужен только для технической проверки организаторами; публично его не размещать.
4. **Код.** Прикрепить новый финальный source archive и соседний `.zip.sha256`. Точное имя должно совпадать с первым слайдом PDF. Это вариант фиксации исходников без git commit, предусмотренный официальным кейсом и FAQ. В архив не включать данные студентов и рабочие секреты.
5. **API.** Если кабинет имеет отдельные поля, прикрепить `openapi.json`, `DATA-API.yaml`, синтетические файлы `tests/fixtures/` из этого же архива. Base URL: https://max.market-kit.ru; интерактивный API: /docs. Сотрудники входят через /admin ключом соответствующего вуза из закрытого PDF. Студент входит через mini-app MAX; браузерное demo — отдельный вымышленный профиль.
6. **Подача.** По предоставленному FAQ срок — 30.09, 12:00 МСК. Перед отправкой сверить последние объявления организаторов, нажать отправку/сохранение в личном кабинете и проверить, что файлы прикрепились. Сообщить разработчику о фактической подаче, чтобы не менять зафиксированную версию.
7. **После подачи.** Оставить сервер и бота включёнными до окончания проверки. Не изменять присланный код и презентацию после дедлайна.

Настоящий тест событий в аккаунтах команды отдельно не заявляется: события/исправление/отмена прошли автоматические и браузерные проверки на вымышленных профилях.
