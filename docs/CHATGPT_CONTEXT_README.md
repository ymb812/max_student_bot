## Как обновлять контекст

Это snapshot, а не автоматическая синхронизация с репозиторием/сервером. При следующем существенном изменении заменить затронутые источники более свежими версиями и указать дату. Не накапливать в одном проекте несколько одноимённых старых snapshot без явной маркировки.

Файлы `.env`, AGENTS.md с рабочими секретами, `.local/`, базы, SSH-креды и закрытые служебные презентации в комплект не входят. При необходимости коллега отдельно получает безопасные исходники или актуальные скриншоты вымышленных профилей от разработчика. Публичная Google Slides-копия — рабочий материал, а не источник истины о текущей реализации.
