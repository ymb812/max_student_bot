## Git и фиксация исходников

Репозиторий локально находится на `main`, **без единого коммита и без remote**. Правило `AGENTS.md` запрещает делать `git commit`. Поэтому push сейчас технически невозможен. Официальный кейс допускает архив исходников с SHA256 вместо Git commit; FAQ рекомендует этот вариант для гарантированного доступа экспертов. `.env`, `AGENTS.md`, данные, резервные копии, локальные артефакты и IDE/caches исключены из Git и source archive. В staged подготовлены 80 файлов: продуктовый код, `docs/`, API contract, fixtures, тесты и Docker-файлы. Архив `.local/release/max_students_mvp_2026-09-30_submission-source.zip` и соседний `.zip.sha256` содержат тот же набор путей и пересобраны после правок приёмки. Перед подачей сверить SHA256 с первым слайдом закрытого PDF.
