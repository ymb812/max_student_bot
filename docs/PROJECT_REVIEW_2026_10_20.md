# Ревью проекта — 20.10.2026

Проверены приложение студента, админка, API, правила пересчета, история, сессии, очередь MAX и fallback LLM. Режим UI-review — **full**, стек FastAPI/SQLite + vanilla JS и существующий CSS, без нового фреймворка. Согласованный дизайн 18–19 октября сохранен. Ревью не является новой юридической сверкой первоисточников: каталог продолжает использовать зафиксированные evidence и безопасные conditional/needs_review.

Основания: MASTER FINAL, research СПбГУПТД/ЛЭТИ, официальные кейс и FAQ, текущая UI/UX-спецификация, отчеты activation/welcome/layout и два указанных пользователем чата. Коммиты не создавались.

## Очистка и воспроизводимость

`welcome/` не используется runtime, Docker и source packager. Четыре дублирующих файла убраны из рабочей структуры; сохранена обратимая копия в игнорируемом `.local/welcome-reference-2026-10-20/`. Требования уже находятся в `WELCOME_IMPLEMENTATION_2026_10_19.md` и UI/UX spec, ресурсы — в `app/static/`. Исторические упоминания welcome обозначены как история, а не обязательный входной файл. README и карта кода актуализированы. Старые product/research/официальные документы сохранены как источники.

Изолированный `scripts/preview_redesign.py` получил только локальные модельные ключи `local-ui-sutd` / `local-ui-leti`. Он привязан к 127.0.0.1, использует свою SQLite, `_env_file=None`, пустой MAX token и disabled transport. Эти ключи не являются учетными данными опубликованного сервера. Новый `check_review_ui.cjs` отказывается публиковать тестовые правила на нелокальном URL.

## Проверки и результаты

Первый проход до изменений: 38 pytest + 6 presentation tests, четыре существующих browser scripts. Воспроизведены университетский 409, неверный заголовок profile history и привязка draft к bearer; дополнительно найдена потеря составных данных и отсутствие проверок queued reminders/LLM JSON.

После исправлений:

- `.venv/Scripts/python.exe -m pytest -q` — **48 passed**. Единственное предупреждение — upstream deprecation alias AnyIO в Starlette TestClient.
- `node --test tests/roadmap-view.test.cjs` — **6 passed**.
- `node scripts/check_student_ui.cjs` — полный путь, уточнения, статусы/reload, событие/исправление/отмена, сохраненный diff, потерянный POST response без дубля, оба адаптера.
- `node scripts/check_activation_ui.cjs` — RU/EN, согласие, late entry, complete/undo, черновики, recheck/read-only, loading/error/retry, удаление и узкие экраны.
- `node scripts/check_welcome_ui.cjs` — первый/продолженный/готовый вход, Back/Forward, целевые ссылки, auth error/retry, модельный MAX Back и rotation, 320–430 px.
- `node scripts/check_student_layout.cjs` — **448 RU/EN checks**, 320/390/430/768/1280/1920/2560 px, все 12 форм событий, общая оболочка, 44px targets, tabs/dialogs, hover.
- `node scripts/check_review_ui.cjs` — полная регрессия найденных проблем: два editor tenant, составное правило/v2/publication/archive, видимый diff, optional event fields/correction, legacy draft, MAX token rotation/account isolation, expired session.
- JS syntax checks и `git diff --check` — без ошибок.

Для browser scripts используется Chromium/Chrome и `PLAYWRIGHT_MODULE`, если Playwright не установлен в стандартном node_modules. API настоящий локальный; подменены только ответы MAX auth для проверки жизненного цикла и сеть для ошибок. Все новые профили review-сценария удаляются, модельные правила архивируются. Отправки настоящих тестовых сообщений нет. Артефакты: `output/project-review/`, `output/activation-v3/`, `output/welcome/`, `output/layout-review/` (не в Git).
