# Демо-профили и хранение данных

Обновлено 27.09.2026. Переключаемые входные данные добавлены по явному запросу пользователя, изменяющему первоначальное ограничение демо scope. Roadmap по-прежнему вычисляется общим rules engine; готовые задачи и юридические даты не прошиты в пресеты.

## Где данные

SQLite на сервере в Docker volume `max-students_max_data`, путь в контейнере `/app/data/max_students.sqlite3`. Профиль, подтверждённые события, статусы задач и история сохраняются независимо от закрытия приложения и пересборки контейнера.

Настоящий вход MAX: backend проверяет подпись и свежесть initData, извлекает MAX user ID и находит соответствующего пользователя. Даты, гражданство и остальные обстоятельства студент заполняет сам; MAX не является источником этих полей. В браузере хранится токен сессии в sessionStorage, а не копия профиля. Текущий TTL сессии — 24 часа. Повторный настоящий запуск из MAX выдаёт новую сессию к тому же профилю.

Браузерное демо получает случайного отдельного пользователя с `max_user_id=null`; его нельзя автоматически связать с реальным аккаунтом. Закрытие вкладки теряет доступ к токенам демо. Демо-профили не отправляют сообщения MAX. Срок удаления после неактивности задаётся настройкой retention; пользователь может удалить выбранный профиль из интерфейса. Приватные резервные копии хранятся отдельно от рабочей базы.

## Переключение

После обычного onboarding откройте «Мои данные». В браузерном демо показаны исходный профиль и четыре кнопки:

| Пресет | Что демонстрирует |
|---|---|
| Не хватает данных | СПбГУПТД, въезд и общежитие известны; возраст, основание, цель и другие обстоятельства неизвестны → conditional. |
| СПбГУПТД · виза · общежитие | Взрослая учебная ветка; M07 рекомендуемое обращение через 7 дней, M08 общежитие — через 12 дней от первого выбора. |
| СПбГУПТД · без визы · частный адрес | Нет визового M07 и нет общежитского срока M08 −50 дней; ранее пройденная биометрия отмечена по данным студента. |
| ЛЭТИ · виза · общежитие | Локальные инструкции ЛЭТИ; «45 дней» без подтверждённой единицы остаётся буквальной формулировкой, без вычисленной даты. |

Каждая кнопка при первом выборе создаёт независимого тестового пользователя через обычные auth/profile API. Его токен сохраняется только в этой вкладке. Повторный выбор возвращает существующие события, статусы и исправленные данные. Исходный профиль не перезаписывается. Переключение не публикует правила. Даты документов задаются относительно московской даты первого выбора; повторный выбор не сдвигает их.

Гражданство «Тестовая страна / Test country» вымышленное. Полный набор пользовательских полей не подтверждает договорные исключения, медицину/биометрию и федеральные сроки. M05/M06 могут перейти из conditional в needs_review; неподтверждённая юридическая дата остаётся null. Рассчитанные даты M07/M08 показываются во вкладке «Скоро», с владельцем и характером рекомендации в подробностях.

На настоящем аккаунте MAX блок переключения отсутствует: требуется `demo_mode` и подтверждённый сервером `roadmap.demo_model`. Presets содержат только входные поля; новые API и обходы авторизации не добавлялись. Истёкшая сессия пресета требует нового тестового пользователя; данные прежней сессии по такому переключению не восстанавливаются.

## Проверки

34 автоматических теста проходят. Тест читает фактические fixtures и проверяет независимые профили/статусы, рассчитанные рекомендации СПбГУПТД, неизвестную единицу ЛЭТИ и отсутствие выдуманных федеральных дат. В браузере проверены заполнение, переключение неполного профиля и возврат к ранее отмеченной задаче «В процессе», а также переход на ЛЭТИ. Публичный smoke обоих вузов, событий, статусов и публикации модельного правила прошёл; синтетические пользователи удалены, модельное правило архивировано.


## Проверка нового экранного UI

Демо-переключатели теперь в корне «Мои данные». Открыть «План» → этап → задачу; «Событие» → форму → сохранённый diff → историю. M07/M08 относятся к «Во время учёбы», но могут быть Hero независимо от current stage. Динамические даты пресета могут не сделать M07 первым действием: приоритет подтверждается фактическим roadmap, а не showcase. Автоматическая проверка: scripts/check_student_ui.cjs; локальный сервер: scripts/preview_redesign.py.
