Уточнения перед сдачей:

Архитектурное решение: один backend и одна SQLite/WAL база вместо лишних микросервисов; vanilla JS/CSS вместо сборки frontend. Отдельный временный tunnel работает в Docker-сети проекта и не меняет production Caddy и занятые порты. Все календарные сравнения движка/напоминаний используют московскую дату; audit timestamps хранятся в UTC и отображаются в истории по Москве. Срок хранения отсчитывается от активности авторизованного студента.

LLM fallback извлекает только тип события/язык и не создаёт тексты новых норм; QA/ответы по праву не автоматизированы. Опубликованные события — user_attested, не office_verified.
