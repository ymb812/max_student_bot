## Вход, черновик и возврат

- До проверки входа показан локализованный статус без CTA. При ошибке доступен «Повторить вход» / «Retry sign-in»; переключение языка сохраняет состояние и повтор не создает demo-аккаунт вместо неуспешной MAX-авторизации.
- Новый авторизованный пользователь без начатой анкеты видит приветствие. CTA записывает только локальный `started=true`, открывает вопрос 1 и переводит фокус на его заголовок. Никакого профильного PATCH, согласия, события или статуса задачи при этом нет.
- Начатая анкета восстанавливает номер вопроса, ответы, язык и явно отмеченное согласие из sessionStorage. Отдельный `started` отличает реальный старт от автоматически созданного пустого черновика. Для старого формата начало определяется ответом о ситуации, въезде, жилье, ненулевым шагом или согласием; один факт существования пустого draft не считается началом.
- Browser Back/Forward, кнопка «Назад» и MAX BackButton сохраняют черновик. Из вопроса 1 можно вернуться к приветствию. Повторный CTA начинает просмотр с вопроса 1, сохраняя выбранные ответы. После reload начатая анкета возобновляется на сохраненном вопросе.
- Browser demo использует прежний scope по bearer token. Для MAX после успешной серверной проверки подписанных launch data используется scope `max_<signed user.id>`, чтобы смена bearer token при повторном входе не теряла черновик. Связь выданного bearer с этим scope сохраняется в sessionStorage: действующая сессия восстанавливает тот же черновик и без повторных launch data. Непроверенный initDataUnsafe не используется для identity. Хранилище остается в пределах browser session; восстановление между устройствами не заявлено.
- После успешного сохранения согласия draft удаляется. Готовый профиль открывает План или допустимый URL/MAX task target без появления приветствия. URL target сохраняется и через незавершенную анкету. Старые записи вопросов в browser history приводят к текущему плану.
- При открытии сохраненной анкеты из новой записи history восстанавливается локальный путь возврата до приветствия. Удаление профиля очищает его черновики; браузерный demo начинает новый вход с приветствия.
